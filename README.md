## 🔭 我在做什么 / What I'm working on

- 🎓 高中在读，这里的代码基本都是课余时间写的
- ✈️ 大部分项目其实在解同一类问题：航空和模拟飞行里那些重复、零散、靠手工点的活 —— 查天气、拼航路、整理照片、出卷子
- 🧰 Python 写得最多：桌面端 PyQt6，网页端 FastAPI + Vue，需要单文件分发的就用 Go（下面那张 Top Languages 里 Go 占八成，基本是一个仓库灌进去的）
- 📻 业余无线电爱好者，连操作证考试的刷题工具都是自己写的
